# Goutham Nidhi — Living Systems

Interactive food systems and sustainability portfolio, with original WebGL artwork, research projects, publications, experience and CV.

## Deployment

GitHub Pages deployment runs on pushes to `main` through `.github/workflows/pages.yml`.
In repository **Settings → Pages**, select **GitHub Actions** as the publishing source.

Expected project URL: https://mephistomythical-ops.github.io/gouthamnidhi1998.github.io/

## Local preview

Open `index.html`, or run `python -m http.server 8000` in this directory and open http://localhost:8000.
No package installation or build is required.

## Editing

- `index.html`: main content, education, experience, contact and thesis links.
- `main.js`: project descriptions and links, filters, dialogs and scrolling.
- `scene.js`: original liquid-metal-style WebGL shader.
- `style.css` and `fonts.css`: responsive layout, colours and fonts.
- `assets/`: images and downloadable CV.

All assets are local. External report links use Google Drive. Check their sharing permissions before sharing the portfolio publicly.
